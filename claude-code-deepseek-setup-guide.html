deepseek-proxy.py Translates API formats
↓

Claude Code speaks Anthropic’s API format. DeepSeek speaks OpenAI’s format.
The proxy translates every request & response in real time — zero dependencies, pure Python stdlib.

2. Install Node.js

Open PowerShell as Administrator and run:

winget install OpenJS.NodeJS.LTS --source winget --accept-package-agreements --accept-source-agreements

After install, refresh your PATH:

$env:Path = [Environment]::GetEnvironmentVariable("Path","Machine") + ";" + [Environment]::GetEnvironmentVariable("Path","User")

Verify:

node --version  # should show v24.x.x or later
npm --version   # should show v11.x.x or later

3. Install Claude Code CLI

npm install -g @anthropic-ai/claude-code@latest

Verify:

claude --version  # should show 2.x.x (Claude Code)

4. Install Python 3.12

winget install Python.Python.3.12 --source winget --accept-package-agreements

Refresh PATH again and install certifi (fixes SSL on some VMs):

$env:Path = [Environment]::GetEnvironmentVariable("Path","Machine") + ";" + [Environment]::GetEnvironmentVariable("Path","User")
pip install certifi

5. Deploy the Proxy Script

Save the file below as deepseek-proxy.py in a convenient folder (e.g. C:\Users\AI_Test\Documents\claude\).

Click to expand — deepseek-proxy.py (v7) 
"""DeepSeek Proxy for Claude Code — v7
Translates Anthropic Messages API <-> DeepSeek OpenAI-compatible API.
Zero dependencies beyond Python stdlib + certifi (for SSL)."""

import json, ssl, sys, uuid
from http.server import HTTPServer, BaseHTTPRequestHandler
from urllib.request import Request, urlopen
from urllib.error import HTTPError

try:
    import certifi
    SSL_CONTEXT = ssl.create_default_context(cafile=certifi.where())
except ImportError:
    SSL_CONTEXT = ssl.create_default_context()

DEEPSEEK_KEY   = "sk-YOUR-DEEPSEEK-API-KEY-HERE"
DEEPSEEK_BASE  = "https://api.deepseek.com/v1"
DEEPSEEK_MODEL = "deepseek-chat"
PORT           = 4000

FAKE_MODELS = [
    {"id": "claude-opus-5",   "type": "model", "display_name": "Claude Opus 5 (DeepSeek V4 Pro)",  "created_at": "2025-06-01T00:00:00Z"},
    {"id": "claude-sonnet-5", "type": "model", "display_name": "Claude Sonnet 5 (DeepSeek V4 Pro)","created_at": "2025-06-01T00:00:00Z"},
    {"id": "claude-fable-5",  "type": "model", "display_name": "Claude Fable 5 (DeepSeek V4 Pro)", "created_at": "2025-06-01T00:00:00Z"},
    {"id": "claude-haiku-4-5","type": "model", "display_name": "Claude Haiku 4.5 (DeepSeek V4 Pro)","created_at": "2024-10-01T00:00:00Z"},
]

def an_to_ds(an: dict) -> dict:
    ds = {"model": DEEPSEEK_MODEL, "messages": [], "stream": False}
    s = an.get("system")
    if s:
        if isinstance(s, str):
            ds["messages"].append({"role": "system", "content": s})
        elif isinstance(s, list):
            parts = [b.get("text","") for b in s if isinstance(b,dict) and b.get("type")=="text"]
            if parts: ds["messages"].append({"role": "system", "content": "\n".join(parts)})
    for m in an.get("messages", []):
        c = m.get("content", "")
        if isinstance(c, list):
            parts = []
            for b in c:
                if not isinstance(b, dict): continue
                t = b.get("type","")
                if t == "text":        parts.append(b.get("text",""))
                elif t == "tool_use":  parts.append(f'[tool_use: {b.get("name","")} {json.dumps(b.get("input",{}))}]')
                elif t == "tool_result": parts.append(f'[tool_result: {b.get("content","")}]')
            c = "\n".join(parts)
        ds["messages"].append({"role": m.get("role","user"), "content": c})
    if "max_tokens" in an:  ds["max_tokens"]  = an["max_tokens"]
    if "temperature" in an: ds["temperature"] = an["temperature"]
    if "top_p" in an:       ds["top_p"]       = an["top_p"]
    if "stop_sequences" in an: ds["stop"]     = an["stop_sequences"]
    tools = an.get("tools")
    if tools:
        ds["tools"] = [{"type":"function","function":{"name":t.get("name",""),
            "description":t.get("description",""),"parameters":t.get("input_schema",{})}} for t in tools]
    return ds

def ds_to_an(ds: dict, an: dict) -> dict:
    choice = ds.get("choices", [{}])[0]
    msg    = choice.get("message", {})
    text   = msg.get("content", "")
    finish = choice.get("finish_reason", "stop")
    blocks = []
    if text:
        blocks.append({"type": "text", "text": text})
    for tc in msg.get("tool_calls", []):
        func = tc.get("function", {})
        try:    args = json.loads(func.get("arguments", "{}"))
        except: args = {}
        blocks.append({"type":"tool_use","id":tc.get("id",f"toolu_{uuid.uuid4().hex[:24]}"),
                        "name":func.get("name",""),"input":args})
    stop_map = {"stop":"end_turn","length":"max_tokens","tool_calls":"tool_use"}
    usage = ds.get("usage", {})
    return {"id":f"msg_{uuid.uuid4().hex[:24]}","type":"message","role":"assistant",
        "model":an.get("model","claude-sonnet-5"),"content":blocks,
        "stop_reason":stop_map.get(finish,"end_turn"),"stop_sequence":None,
        "usage":{"input_tokens":usage.get("prompt_tokens",0),"output_tokens":usage.get("completion_tokens",0)}}

class H(BaseHTTPRequestHandler):
    def log_message(self, f, *a): pass
    def _send(self, data, status=200):
        body = json.dumps(data, ensure_ascii=False).encode()
        self.send_response(status)
        self.send_header("Content-Type","application/json")
        self.send_header("Content-Length",str(len(body)))
        self.send_header("Access-Control-Allow-Origin","*")
        self.end_headers()
        self.wfile.write(body)
    def _read(self) -> dict:
        length = int(self.headers.get("Content-Length", 0))
        return json.loads(self.rfile.read(length).decode()) if length else {}
    def _call_ds(self, ep: str, body: dict = None) -> dict:
        url = f"{DEEPSEEK_BASE}{ep}"
        h   = {"Authorization":f"Bearer {DEEPSEEK_KEY}","Content-Type":"application/json"}
        req = Request(url, data=json.dumps(body).encode() if body else None,
                      headers=h, method="GET" if body is None else "POST")
        try:
            with urlopen(req, timeout=180, context=SSL_CONTEXT) as r:
                return json.loads(r.read().decode())
        except HTTPError as e:
            print(f"  !! DeepSeek [{e.code}]: {e.read().decode(errors='replace')[:500]}", flush=True)
            raise
    def do_GET(self):
        p = self.path.split("?")[0]
        print(f"  GET {p}", flush=True)
        if p == "/v1/models":
            self._send({"object":"list","data":FAKE_MODELS,"has_more":False,
                        "first_id":FAKE_MODELS[0]["id"],"last_id":FAKE_MODELS[-1]["id"]})
        elif p.startswith("/v1/models/"):
            mid = p.split("/v1/models/")[1]
            self._send({"id":mid,"type":"model","display_name":f"DeepSeek V4 Pro (as {mid})",
                        "created_at":"2025-06-01T00:00:00Z"})
        elif p == "/health":
            self._send({"status":"ok"})
        else:
            print(f"  ?? UNKNOWN GET: {p}", flush=True)
            self._send({"error":f"not found: {p}"}, 404)
    def do_POST(self):
        p = self.path.split("?")[0]
        print(f"  POST {p}", flush=True)
        if p == "/v1/messages":
            try:
                an   = self._read()
                print(f"    model={an.get('model')} msgs={len(an.get('messages',[]))} max_tok={an.get('max_tokens')}", flush=True)
                ds   = an_to_ds(an)
                resp = self._call_ds("/chat/completions", ds)
                out  = ds_to_an(resp, an)
                print(f"    -> {out['stop_reason']} in={out['usage']['input_tokens']} out={out['usage']['output_tokens']}", flush=True)
                self._send(out)
            except Exception as e:
                print(f"    !! ERROR: {e}", flush=True)
                self._send({"type":"error","error":{"type":"api_error","message":str(e)}}, 500)
        else:
            print(f"  ?? UNKNOWN POST: {p}", flush=True)
            self._send({"type":"error","error":{"type":"invalid_request_error","message":f"not found: {p}"}}, 404)
    def do_OPTIONS(self):
        self.send_response(200)
        self.send_header("Access-Control-Allow-Origin","*")
        self.send_header("Access-Control-Allow-Methods","GET,POST,OPTIONS")
        self.send_header("Access-Control-Allow-Headers","*")
        self.end_headers()

if __name__ == "__main__":
    port = int(sys.argv[1]) if len(sys.argv) > 1 else PORT
    print(f"\n  Proxy: http://localhost:{port}\n  -> DeepSeek: {DEEPSEEK_MODEL} @ {DEEPSEEK_BASE}\n", flush=True)
    HTTPServer(("0.0.0.0", port), H).serve_forever()
ⓘ How the proxy works: It listens on 0.0.0.0:4000 and presents itself as a standard Anthropic API endpoint. Claude Code thinks it’s talking to claude-opus-5 or claude-sonnet-5. Behind the scenes, every request is translated to OpenAI format and forwarded to DeepSeek’s API.

6. Launch Claude Code

Terminal 1 — Start the proxy

python deepseek-proxy.py

You should see:

  Proxy: http://localhost:4000
  -> DeepSeek: deepseek-chat @ https://api.deepseek.com/v1

Terminal 2 — Launch Claude Code

$env:ANTHROPIC_BASE_URL = 'http://localhost:4000'
$env:ANTHROPIC_API_KEY  = 'any-value'
claude
⚠ Critical: Do NOT include /v1 in the BASE_URL. Claude Code appends it automatically. Using http://localhost:4000/v1 will result in double paths (/v1/v1/messages) and break everything.

When prompted about the API key, select Yes.

Claude Code will auto-detect the models from the proxy. Select claude-sonnet-5 (or any listed model) — all routes go to DeepSeek V4 Pro.

7. Verify Everything Works

Check the proxy terminal

When you send a message in Claude Code, the proxy terminal should show:

  GET /v1/models
  POST /v1/messages
    model=claude-sonnet-5 msgs=1 max_tok=4096
    -> end_turn in=15 out=52

8. Bugs Encountered & Fixes

BugSymptomFix
winget msstore source 0x8a15005e : The server certificate did not match Add --source winget
refreshenv not found CommandNotFoundException Reload PATH from registry manually
LiteLLM needs Rust/MSVC linker `link.exe` not found Switched to pure Python proxy
SSL cert verify failed CERTIFICATE_VERIFY_FAILED Install certifi + use ssl.create_default_context()
Model not found There's an issue with the selected model Echo exact model ID back (including [1m] suffix)
Double /v1 path POST /v1/v1/messages Remove /v1 from ANTHROPIC_BASE_URL
